这个站点用 Jekyll + GitHub Pages 搭成，左边目录树、右边正文，做法和思源笔记差不多：**一个 `.md` 文件就是一篇笔记，提交之后自动出现在左边目录里**。

## 一、加一篇新笔记

打开仓库：<https://github.com/Toxic1-sudo/Toxic1-sudo.github.io>

进入 `_posts/` 目录 → 右上角 **Add file → Create new file** → 文件名按下面的规则写。

## 二、文件名规则（唯一硬性要求）

```
年-月-日-标题.md
```

例如：

```
2026-11-08-kioptrix-level-1.md
2026-11-12-sqli-bypass.md
```

- 日期必须补零：`11` 不能写成 `11月`，`6` 要写成 `06`
- 标题里**不要有空格**，用 `-` 连接
- 不要写 `.markdown`，统一 `.md`

## 三、开头必须有这一段

两行 `---` 之间叫 front matter，它决定这篇笔记怎么归类：

```yaml
---
title: "Kioptrix Level 1 打靶记录"
date: 2026-11-08 20:00:00 +0800
categories: [靶机]
tags: [Kioptrix, Samba, 提权]
---
```

| 字段 | 作用 | 注意 |
|---|---|---|
| `title` | 左边目录里显示的名字 | 含空格或冒号要用双引号包住 |
| `date` | 发布时间，决定排序 | 带 `+0800` 是东八区，不写会按 UTC 算 |
| `categories` | **左边目录的文件夹名** | 同一个分类的笔记会自动归到一个文件夹 |
| `tags` | 标签 | 暂时不影响显示，以后能加标签页 |

**`categories` 就是思源笔记里的「笔记本 / 文档树」**。写 `[靶机]` 就归到「靶机」这个文件夹里；想单独放就写 `[杂记]`、`[Web安全]`、`[密码学]` 之类的。

## 四、正文就是普通 Markdown

标题、列表、表格、代码块都能用。代码块记得标语言，不然没有高亮：

````markdown
```bash
nmap -sV -p- 172.20.10.12
```
````

图片可以直接把文件拖进 GitHub 的编辑框，它会自动生成链接。

## 五、提交之后

点 **Commit changes**，等大约 1 分钟，刷新页面就能看到。

构建有没有成功，看仓库顶部的 **Actions** 标签：

- ✅ 绿勾 = 编译成功
- ❌ 红叉 = 出错，点进去看日志，最常见的原因是 front matter 少了 `---`，或者 YAML 里冒号没加引号

## 六、左边目录点不开 / 是空的

三种可能：

1. 文件名日期格式不对（比如 `2026-11-8` 少了个 `0`）
2. `categories` 写成了 `category`
3. 文件没放进 `_posts/` 目录，放到了仓库根目录

对不上就回来改，别删了重建。
